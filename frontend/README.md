# Interfaz de Nodaly

Desde esta carpeta, ejecuta `npm install` y después `npm run dev`. Abre la dirección local indicada. El servidor de desarrollo de Vite redirige `/api` a `http://127.0.0.1:8000`; inicia primero el servidor de Python. Ejecuta `npm test` y `npm run build` para comprobar las pruebas y la compilación.

Elige una plantilla, selecciona los nodos para configurarlos y conecta sus puntos de entrada y salida. Guarda el flujo para conservarlo entre reinicios. En el modo de demostración local las respuestas usan coincidencias de texto, no un modelo de lenguaje. El proveedor de IA opcional se configura únicamente en el servidor, nunca en la interfaz.

La interfaz y los mensajes están en español. Las claves y los valores internos de la API se conservan para no modificar los datos existentes. Los nombres personalizados, documentos y mensajes introducidos por el usuario no se traducen automáticamente.
